# Support

Support and feedback happen in public on GitHub Issues, best effort, with no guaranteed response time. There is no email, chat or paid support.

- **Bug:** use the *Bug report* form. Say which browser, what you expected, what you saw, and include a **synthetic** reproduction
  (a small HTML snippet with fictional hosts, or the [synthetic test page](https://decarvalhoe.github.io/capital-ops-horizon-consent-inventory/examples/synthetic-page.html)).
- **Feedback or idea:** use the *Feedback* form. Telling us whether you actually used the tool on a real page (without naming it if it is not public) helps most.

## Do not send private data

Issues are public and permanent. Do not paste: the JSON output of a non-public page, cookie or storage values, session identifiers, tokens,
personal data, or a client's site name without permission. Rebuild the case with fictional hosts (for example under `.invalid`) first.
Anything private posted by mistake should be deleted by its author; we will ask for it to be removed.
